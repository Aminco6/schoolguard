One touch in. One touch out.

Parents don’t need to type anything. They place a finger on the gate terminal, the app records it, and the school hears the announcement.

  1. Parent places a finger on the scanner
  2. Scanner reads and matches the fingerprint
  3. Terminal sends it to the phone over school Wi-Fi
  4. App records the check-in or pick-up
  5. Voice announces it

Install in 4 steps

Download. Allow. Install. Open.

The app installs straight from the APK file, so Android will ask you to allow it once.

01
⬇️

Download the APK

Tap Download APK on the phone you will use at the gate.

02
🔓

Allow installs

If Android asks, allow your browser to install unknown apps. One-time setting.

03
📲

Install

Open the downloaded file and tap Install.

04
📶

Join school Wi-Fi

Connect to the school’s local Wi-Fi so the app can reach gates and speakers, then sign in.

🔒 Only install the APK from this official page or from the school’s installer. The app works with the gate terminals and audio units from the SchoolGuard kit.
